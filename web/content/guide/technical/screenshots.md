For a bug report, a screenshot from Windows, Steam or another capture tool isn't good enough. Screenshots taken with the game's own screenshot key carry metadata that lets the technical team find the exact moment in your [client log](/guide/technical/client-logs/) where the problem appeared. Without that link, the picture is much less useful.

## How to take one

1. Check the key binding first. It's under **Controls → Common → Interface → Screenshot**.
2. When the problem shows up, press your Screenshot key.
3. Find the image in the `Screenshots` folder in the game's install directory.
4. Upload the original file directly to the bug-reporting website and attach that link to your report.

## Don't use image hosts

Services such as Imgur strip the metadata from images when you upload them. A screenshot shared that way loses exactly the information that made it worth taking in-game, so always upload the original file straight to the reporting site.
