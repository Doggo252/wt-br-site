"Game integrity" means that every file the game needs is present, unmodified, and in the right place. A missing or damaged file can cause crashes and odd behaviour, so before you report a technical problem you should run a file check. That way you and the support team can rule out a broken installation straight away.

How you do it depends on where you installed the game.

## Installed from the Gaijin website

1. Open the War Thunder launcher as you normally would.
2. Click the wrench icon in the top right corner of the launcher.
3. Click "Check files".
4. Wait for the check to finish.

## Installed through Steam

1. Open your Steam library.
2. Right-click War Thunder and choose "Properties".
3. Go to the "Local files" tab and click "Verify integrity of game files...".
4. Wait for the check to finish. A pop-up window shows how far along it is.

If the problem still happens after a clean check, try [clearing the game cache](/guide/technical/game-cache/) as well before you report it.
